# Ressources de marque

- `agro-marks-logo.png` : logo officiel AGRO-MARKS (fichier original fourni, 1280 × 1280, non retouché). Utilisé dans l'en-tête, le pied de page et les données structurées.
- `agro-marks-logo-alt.png` : variante fournie, conservée pour d'autres usages.

Les icônes `src/app/icon.png` (256 × 256) et `src/app/apple-icon.png` (180 × 180) sont des réductions du logo officiel. Pour changer de logo, remplacer le fichier et mettre à jour `src/config/brand.ts`.
