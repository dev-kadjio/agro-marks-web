# Ressources de marque

Toutes les déclinaisons sont tirées du visuel officiel fourni (`agro-marks-logo-full.png`, 896 × 1120, conservé tel quel).

- `agro-marks-logo-vertical.png` : logo principal complet (monogramme « AM », nom et mention), recadré sans fond superflu, 596 × 716. Utilisé dans l'en-tête, le pied de page et les données structurées.
- `agro-marks-mark.png` : monogramme « AM » seul, centré avec une marge régulière, 560 × 560. Source des icônes du site.
- `agro-marks-logo-alt.png` : ancienne variante, conservée pour d'autres usages.

Les icônes `src/app/icon.png` (256 × 256) et `src/app/apple-icon.png` (180 × 180) sont des réductions de `agro-marks-mark.png`. Pour changer de logo, remplacer le fichier et mettre à jour les dimensions dans `src/config/brand.ts`.
